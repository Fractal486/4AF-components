4AF Components is a personal library of polished, reusable React components. It is built on
[Base UI](https://base-ui.com/) for behavior, designed around composable APIs, and distributed
through a shadcn-compatible registry at `https://4af.selfsimilar.dev`.

The library is intentionally small. Each component is refined to share the same tokens,
motion rules, accessibility expectations, and installation workflow instead of becoming a
collection of unrelated snippets.

The catalog currently contains **<ComponentCount /> installable components**. The generated
[component catalog](/docs/reference/components) always matches the registry, while the
[Agent Skill](/docs/reference/agent-skill) packages the workflow and reference material for
coding agents.

## What the library values

- **Base UI behavior.** Focus management, dismissal, keyboard navigation, and other interaction
  primitives come from Base UI rather than hand-rolled copies.
- **Composable APIs.** Components forward props and refs, expose variants through CVA, and keep
  state available on the DOM for styling and testing.
- **Semantic styling.** Components consume the 4AF theme's semantic color, radius, elevation,
  and motion tokens instead of hard-coded colors or durations.
- **Portable installation.** Components can be installed into another shadcn-compatible project
  with the 4AF CLI, including the shared theme and utilities they need.

## Install a component

In a project with a shadcn `components.json`:

```bash
npx shadcn@latest add https://4af.selfsimilar.dev/r/button.json
```

Replace `button` with any component from the catalog. The theme, shared utilities, and the
components it builds on install with it.

From a clone of this repository, the 4AF CLI also checks the target project, previews every file,
and refuses to overwrite files unless told to:

```bash
pnpm 4af list
pnpm 4af doctor --project <absolute-target-project>
pnpm 4af install button --project <absolute-target-project>
```

## Use a component

After installation, import the component from the target project's `components/ui` alias:

```tsx
import { Button } from "@/components/ui/button";

export function DeployButton() {
  return <Button variant="primary">Deploy</Button>;
}
```
