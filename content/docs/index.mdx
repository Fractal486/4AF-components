4AF Components is a personal library of React components. It is built on
[Base UI](https://base-ui.com/) and distributed through a shadcn registry at
`https://4af.selfsimilar.dev`.

Every component uses the same tokens and motion settings, so components can be combined without
style adjustments.

The catalog currently contains **<ComponentCount /> installable components**. The generated
[component catalog](/docs/reference/components) always matches the registry, while the
[Agent Skill](/docs/reference/agent-skill) packages the install workflow and reference material
for coding agents.

## Design and behaviour

- **Visual style.** Compact controls, warm-neutral greys, and a single amber accent used for
  focus rings.
- **Motion.** Animations mark state changes, such as presses, content swaps, and panels opening
  or closing. They last 150 to 450ms and follow the reduced-motion setting.
- **Implementation.** Behaviour comes from Base UI and styling from semantic tokens. Every
  component forwards props and refs and works controlled or uncontrolled. The full rules are in
  [Engineering](/docs/reference/engineering).

## Install a component

In a project with a shadcn `components.json`:

```bash
npx shadcn@latest add https://4af.selfsimilar.dev/r/button.json
```

Replace `button` with any component from the catalog. The theme, shared utilities, and the
components it builds on install with it. [Installation](/docs/reference/installation) covers
short names, previewing changes, and updating.

## Use a component

After installation, import the component from the target project's `components/ui` alias:

```tsx
import { Button } from "@/components/ui/button";

export function DeployButton() {
  return <Button variant="primary">Deploy</Button>;
}
```
