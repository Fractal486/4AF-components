4AF Components is a personal library of minimal React components with just enough motion. It
is built on [Base UI](https://base-ui.com/) and distributed through a shadcn registry at
`https://4af.selfsimilar.dev`.

The library is intentionally small, and every component shares the same tokens and motion, so
any two of them sit together without adjustment.

The catalog currently contains **<ComponentCount /> installable components**. The generated
[component catalog](/docs/reference/components) always matches the registry, while the
[Agent Skill](/docs/reference/agent-skill) packages the workflow and reference material for
coding agents.

## What the library values

- **Minimal by default.** Compact controls, warm-neutral greys, and one amber accent kept for
  focus. Nothing is decorative.
- **Just enough motion.** Animation marks a change, such as a press, a swap, or a panel opening
  or closing. It is short, never makes you wait, and turns down with the reduced-motion setting.
- **Solid underneath.** Behaviour comes from Base UI, styling from semantic tokens, and every
  component forwards props and refs and works controlled or uncontrolled. The full rules are in
  [Engineering](/docs/reference/engineering).

## Install a component

In a project with a shadcn `components.json`:

```bash
npx shadcn@latest add https://4af.selfsimilar.dev/r/button.json
```

Replace `button` with any component from the catalog. The theme, shared utilities, and the
components it builds on install with it. [Installation](/docs/reference/installation) covers
short names, previewing changes, and updating.

## Use a component

After installation, import the component from the target project's `components/ui` alias:

```tsx
import { Button } from "@/components/ui/button";

export function DeployButton() {
  return <Button variant="primary">Deploy</Button>;
}
```
