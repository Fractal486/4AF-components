---
title: Agent Skill
description: Guidance for agents choosing, installing, and integrating 4AF components.
---

The 4AF Components skill is the agent-facing guide to the library. It helps an agent choose
components, read their documentation, and install them into another project with the shadcn
CLI.

Install it with the [skills.sh](https://skills.sh) CLI:

```bash
npx skills add Fractal486/4AF-components --skill 4af-components
```
