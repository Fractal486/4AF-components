## API

**Main export:** `MatrixLoader`

A 4×4 grid of dots. `variant="scan"` (default) pulses columns together from left to right;
`variant="twinkle"` staggers individual dots in a fixed order.

| Prop | Default | Description |
| --- | --- | --- |
| `size` | `"sm"` | Dot size and gap: `"sm"` uses 2px / 2px, `"md"` uses 3px / 2px, and `"lg"` uses 4px / 3px. |
| `duration` | `1.2` | Seconds per cycle. Non-positive or non-finite values fall back to `1.2`. |
| `label` | — | An accessible status name; omit it for a decorative loader. |

Native `div` props, `className`, `style`, and an element `ref` are supported.

Pass `label` when the loader itself should announce a busy status. Leave it out when nearby text
already says what is loading.

The loop keeps its duration under reduced motion rather than collapsing into a strobe.
