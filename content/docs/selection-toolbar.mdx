## API

**Main exports:** `SelectionToolbar`, `SelectionToolbarButton`,
`SelectionToolbarActionButton`, `SelectionToolbarToggle`, `SelectionToolbarActionToggle`,
`SelectionToolbarToggleGroup`, `SelectionToolbarSeparator`, `useSelectionToolbar`

A bar of actions over selected text, styled like a tooltip. A Base UI Popover anchors it to the
selected range, so it follows the text while scrolling, and Base UI Toolbar handles arrow-key
focus. Pressing an item doesn't collapse the selection. Use the toolbar's item components to
join that keyboard navigation and receive the captured text and range through their action APIs.

### Root props

| Prop | Default | Description |
| --- | --- | --- |
| `children` | Required | The region whose text selections are watched; selections elsewhere are ignored. |
| `actions` | Required | React node containing toolbar buttons, toggles, separators, or other content. |
| `asChild` | `false` | Attaches the watched region to the child element instead of adding a wrapping `div`. |
| `disabled` | `false` | Stops watching selections and closes an open toolbar. |
| `label` | `"Selection actions"` | Accessible toolbar name, announced when focus enters it. |
| `side` | `"top"` | Preferred side of the selected range, using Base UI's Popover positioning. |
| `align` | `"center"` | Alignment along that side: `start`, `center`, or `end`. |
| `sideOffset` | `8` | Gap from the selection, in pixels. |
| `className` | — | Classes for the watched region. |
| `toolbarClassName` | — | Classes for the floating toolbar. |
| `onOpenChange` | — | `(open: boolean) => void`; reports committed visibility changes. |
| `ref` | — | Ref to the watched region, not the floating toolbar. |

`onOpenChange(open)` reports each committed visibility change once: opening on selection,
closing when selection collapses or leaves the region, dismissal by an action or Escape, and
closing when disabled. Repeated selection events and cancelled outside presses do not notify
again. Initial closed state, callback replacement, and unmount do not emit notifications.

Items are 24px high with 4px corners inside the toolbar's 8px shell and 4px padding,
including icon-only forms.

## Item kinds

The items match the menu's row types, without nested panels. Each is built on the matching
library component.

| Item | Built on | Default dismissal |
| --- | --- | --- |
| `SelectionToolbarButton` | Button | Dismisses; `keepOpen` opts out |
| `SelectionToolbarActionButton` | Action Button | Stays; `closeOnSuccess` opts in |
| `SelectionToolbarToggle` | Toggle | Stays open |
| `SelectionToolbarActionToggle` | Action Toggle | Stays open |
| `SelectionToolbarToggleGroup` | Base UI `ToggleGroup` in `Toolbar.Group` | — |
| `SelectionToolbarSeparator` | Base UI `Toolbar.Separator` | — |

Actions receive the captured selection through `onAction(text, range)` or `action(text, range)`
on buttons, and `onAction(pressed, text, range)` or `action(pressed, text, range)` on toggles.
Use these instead of
`window.getSelection()`, which may have changed by the time the handler runs.

`variant="destructive"` uses red text on a neutral hover rather than a solid red fill, like the
menu's destructive row.

For state derived from the active range, render a small child component and call
`useSelectionToolbar()` inside it:

```tsx
function HighlightToggle() {
  const { range } = useSelectionToolbar();
  return <SelectionToolbarToggle pressed={isHighlighted(range)} … />;
}
```
