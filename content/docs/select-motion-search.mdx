## API

**Main exports:** `MotionSearchSelect` and its input, content, and item parts

An editable Base UI Combobox whose panel unfolds from the field. It supports single and
checkbox-based multi-selection.

## Sizing

`size="sm"` is the 30px compact control and `size="md"` is the 34px form-row control.
The input trigger and its option rows share the selected size.

## Item data

Because this component is Combobox-based, an item is also its value. Put `icon` on the item data
when a preselected value must display its icon before the popup mounts. No type change is needed:
Base UI types Combobox `items` as `readonly any[]`. An icon passed only to the item element cannot
resolve before mount because nothing outside the popup has seen it. Resolution order is the
mounted item, then `iconForValue`, then the value's own `icon`.
