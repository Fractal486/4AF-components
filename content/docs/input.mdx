## API

**Main export:** `Input`

A Base UI input with default, plain, and underline structures; neutral or accent focus; invalid
and disabled states; and custom number steppers.

## Sizing

The default field is 34px high, matching the medium Button and Select controls. Use `className` when a field needs a deliberately different height.
