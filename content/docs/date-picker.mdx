## API

**Main exports:** `DatePicker`, `DateRangePicker`, `Calendar`, `CalendarDayButton`, type `DateRange`

### DatePicker and DateRangePicker

| Prop | Default | Description |
| --- | --- | --- |
| `value` | — | Controlled value: `Date \| null`, or `DateRange \| null` for the range picker. |
| `defaultValue` | `null` | Uncontrolled initial value. |
| `onValueChange` | — | Called with the new value, or `null` when cleared. |
| `open` / `defaultOpen` / `onOpenChange` | — / `false` / — | Controlled or uncontrolled panel state. |
| `variant` | `"default"` | `"default"` boxed field, `"ghost"`, or `"plain"` (no surface, border, or horizontal padding). `default` and `ghost` are as wide as the panel; `plain` fits its text. The calendar icon sits at the end of the field. |
| `size` | `"md"` | `"xs"` (24px), `"sm"` (30px), or `"md"` (34px). |
| `placeholder` | `"Pick a date"` / `"Pick a date range"` | Trigger text while empty. |
| `title` | `"Select a date"` / `"Select dates"` | Popover accessible name. |
| `locale` | `"en-US"` | BCP 47 locale for the `medium` trigger label (`Intl.DateTimeFormat`, `dateStyle: "medium"`). The grid and the month / year picker follow `calendarProps.locale`. |
| `dateFormat` | `"medium"` | `"medium"` shows the locale's medium date (Oct 19, 2026); `"numeric"` shows day / month / year in zero-padded numbers with dimmed separators (19 / 10 / 2026), in that order in every locale. A range shows both ends. |
| `clearable` | `false` | Adds a Clear action to the panel once a value is set. |
| `clearLabel` | `"Clear"` | Clear action text. |
| `todayLabel` | `"Today"` | Current-month navigation action text. Shown on the left with an Undo2 icon; Clear stays on the right. |
| `showToday` | `true` | Shows the Today action. Set `false` to hide it; the footer disappears when neither Today nor Clear is visible. |
| `name` | — | Renders a hidden input: `YYYY-MM-DD`, or `YYYY-MM-DD/YYYY-MM-DD` for a range. |
| `calendarProps` | — | Forwarded to `Calendar`: `disabled`, `startMonth`, `endMonth`, `captionLayout`, `weekStartsOn`, `locale` (a react-day-picker locale), etc. |

Other button props (`id`, `disabled`, `aria-*`, `className`, `ref`) go to the trigger. The trigger
exposes `data-slot="date-picker-trigger"`, `data-variant`, `data-size`, `data-empty` while no value is
set, and Base UI's `data-popup-open`.

### Calendar

`Calendar` takes every react-day-picker `DayPicker` prop. Key defaults:

| Prop | Default | Description |
| --- | --- | --- |
| `showOutsideDays` | `true` | Shows adjacent-month days. |
| `fixedWeeks` | `false` | Shows only the weeks needed for the displayed month, without extra rows made entirely of adjacent-month days. Set `true` to force six rows. |
| `weekStartsOn` | `1` | Weeks start on Monday. Set `0` for Sunday, or pass `calendarProps.weekStartsOn` through either picker. |
| `formatters.formatWeekdayName` | Narrow weekday | Single-letter weekday headings in English (M T W T F S S), localized through the calendar locale. Override through `formatters` or `calendarProps.formatters`. |
| `navLayout` | `"around"` | Previous/next buttons flank the caption. They are 30px ghost `Button`s (`size="icon-sm"`) with the press spring; an unavailable month renders them `disabled`. |
| `animate` | `true` | Month-change transition. `false` disables it. |

Day buttons expose `data-today`, `data-selected-single`, `data-range-start`, `data-range-middle`, and
`data-range-end`. Weeks and caption expose `data-enter="next" | "prev" | "fade"` after a month change.

Each day button fills its cell, so the whole cell is clickable, but draws its marks as a box 2px
inside it: hover, selection, the focus ring, and today's 1px outline.
Cells are 34px square with a 30px visible box on every device.

## Month and year picker

The caption is a button: the month and year, then an up-down chevron. It toggles a picker that
replaces the day grid, at the same size: months and years in two scrollable columns, side by
side. Picking a year moves the calendar and keeps the picker open; picking a month returns to
that month's days. Each column is a radio group, so it is one tab stop and arrow keys move
through it. Escape returns to the days without closing the panel; a second Escape closes it.
The toggle carries `aria-expanded`.

Months entirely outside `startMonth` / `endMonth` are disabled. Years run from `startMonth`, or
100 years back, to `endMonth`, or 20 years ahead. The picker is part of the default `label`
caption; the `dropdown` caption layouts keep their own selects, and `disableNavigation` renders
a plain caption.

Parts: `data-slot="calendar-picker-toggle"` (the caption button), `calendar-picker` (the two
columns), and `calendar-month-grid` (the wrapper that holds the grid's height while the picker
is open).

## Behavior

- Both pickers use a trigger-anchored `Popover` with the same calendar sizing on every device.
- On open, focus goes to the selected day, else today, else the first enabled day.
- A single date commits and closes on click.
- Today returns to the current month without changing the selection or closing the panel. A draft range is preserved. It respects `today`, `timeZone`, month bounds, and `disableNavigation`; controlled calendars receive `onMonthChange`.
- A range commits and closes on the second click, in either order. The first click of a new pick
  starts a fresh range. Dismissing mid-pick keeps the previous value.
- While one end of a range is chosen, hovering or focusing a day previews the band.
- Both pickers show one month. A range keeps its first pick while navigating to another month.
- The today marker is drawn after hydration and rolls over at midnight. Passing `today` or
  `timeZone` turns this off.

## Motion

- Pointer navigation: weeks slide 24px and the caption 10px from the direction travelled, with a
  fade. Keyboard navigation: fade only.
- CSS only (`@starting-style` on `translate` and `opacity`), using the duration tokens; collapses
  under reduced motion.
- The panel enters and exits with the Popover motion.
- Month height changes animate over the slow duration token as the number of week rows changes. The measured height transition follows reduced-motion tokens and is disabled by `animate={false}`.

## Dependencies

Installs `react-day-picker` and the `popover` and `button` components.
