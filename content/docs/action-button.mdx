## API

**Main export:** `ActionButton`

Runs an `action` that may return a promise, shows pending, success, and error states, then
reverts to idle after `revertAfter` milliseconds (2000 by default). Throw or reject from
`action` to show an error. `pendingDelay` defaults to 0, and concurrent presses cannot start
another run. By default the button keeps the width of its widest state throughout.

While pending, the button keeps keyboard focus and exposes `aria-disabled="true"` and
`aria-busy="true"`. Repeat activation is blocked. An explicit `disabled` prop still disables
the native button unless you opt into `focusableWhenDisabled`.

`onSuccess` and `onError` report the action's outcome even if the button unmounts before it
settles. Unmounting stops local feedback and reset timers, but does not cancel the action.

`sizing="current"` fits the button to the showing state and animates the width as it changes.
A label-only button then reserves no glyph slot while idle and grows when the status glyph
appears. The button carries `data-sizing`.

`size` uses the Button scale: `xs` is 24px, `sm` is 30px, `md` is 34px, and `lg` is 38px. The
square icon sizes are `icon-xs`, `icon-sm`, `icon`, and `icon-lg`.

Without a resting `icon`, the idle label stays centred despite the reserved status-glyph space.
When a glyph is visible, the glyph and label are centred as a group. `iconPosition="end"` puts
the icon and the status glyphs that replace it after the label; the button carries
`data-icon-position`.

`pendingMode` sets the pending presentation:

| `pendingMode` | Pending state |
| --- | --- |
| `"label"` (default) | The pending label beside the loader. |
| `"icon"` | The label morphs out and the loader morphs in, centred in the label-sized box. The button keeps its width, and the resting label stays its accessible name while `aria-busy` and `announce` describe the work. |

```tsx
<ActionButton
  action={() => saveChanges()}
  pendingMode="icon"
  labels={{ success: "Saved", error: "Try again" }}
  announce={{ pending: "Saving changes" }}
>
  Save changes
</ActionButton>
```

## Waiting states

`loader={<MySpinner />}` sets this button's indicator, and
[LoaderProvider](/docs/reference/engineering#shared-loading-indicators) sets a default for a
subtree. `ClassicLoader` is the fallback. Copy Button inherits the slot; Action Toggle also
accepts a `loader` for its pending state.

A label only animates when it changes. Pass `labels={{ pending: "Saving" }}` when the word should
change, and leave it out when only the glyph should move. With `pendingMode="icon"`,
`labels.pending` is not shown.
