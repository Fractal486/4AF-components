## API

**Main export:** `ActionButton`

Runs asynchronous work and presents idle, pending, success, and error states without changing
width, then reverts.

`size` uses the Button scale: `xs` is 24px, `sm` is 30px, `md` is 34px, and `lg` is 38px.
The corresponding square icon sizes are `icon-xs`, `icon-sm`, `icon`, and `icon-lg`.

When no resting icon is provided, the visible label remains centred even though the pending and
outcome glyphs reserve their space. Actions with an icon keep the icon-and-label group centred.

`pendingMode` controls the pending presentation. It defaults to `"label"`, which keeps the
pending label beside the shared loader. Set it to `"icon"` to hide the pending label and centre
the loader over the same label-sized content box. The invisible sizer keeps the button width
stable, and the resting label remains its accessible name while `aria-busy` and `announce`
describe the work:

```tsx
<ActionButton
  action={() => saveChanges()}
  pendingMode="icon"
  labels={{ success: "Saved", error: "Try again" }}
  announce={{ pending: "Saving changes" }}
>
  Save changes
</ActionButton>
```

## Waiting states

Supply `loader={<MySpinner />}` for this button, or use
[LoaderProvider](/docs/reference/engineering#shared-loading-indicators) for a subtree default.
ASCII is the fallback; Copy Button and Delete Button inherit the slot. The former SVG `Spinner`
export is deprecated and now follows the provider too.

The glyph and label morph in **separate boxes** in Action Button, Action Toggle, and the menu's
action row. A reserved glyph box keeps the label in place across either loader style and
the success/error icons.

That split matters at the call site: a label with no per-state override does not animate. Pass
`labels={{ pending: "Saving" }}` when the word should change, and leave it out when only the
glyph should move in the default mode. Use `pendingMode="icon"` when the pending state should
show only the centred loader; `labels.pending` is then ignored visually while the button keeps
the label-sized geometry.

Action Toggle follows the same rule for its glyph: with `fillIcon` and no `icons.pressed`, it
does not swap the glyph on press because there is nothing to morph to, and a fill transition plus
a morph on one element fight over it.
