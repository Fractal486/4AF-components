## API

**Main export:** `AsciiLoader`

A looping braille spinner.
[LoaderProvider](/docs/reference/engineering#shared-loading-indicators) and component `loader`
slots accept it as a custom indicator.

| Prop | Default | Description |
| --- | --- | --- |
| `speed` | `0.8` | Seconds per cycle; a larger value makes the spinner slower. This differs from ClassicLoader's playback multiplier. |
| `loading` | `true` | Whether to show the spinner. `false` renders nothing, removes the accessible status, and stops the animation timer. Visibility changes immediately; no space is reserved. |
| `label` | — | An accessible status name. Without it, the spinner is decorative and hidden from assistive technology. |
| `className` | — | Classes for the outer span. |
| Native span props and `ref` | — | `id`, `aria-*`, `data-*`, `style`, handlers, and `ref<HTMLSpanElement>` reach the outer span. Explicit ARIA props override the defaults from `label`. |

The root stays a span and exposes `data-slot="ascii-loader"` and `data-loading` while mounted.
Its glyph is managed internally; `children`, `asChild`, and `render` are not supported.

Under reduced motion, the cycle takes 2.5 times as long; it continues to animate.

The glyph follows the surrounding font size. Passed as a component's `loader`, it sits centred
in the loader slot, which reserves the same box as the icons around it, so swapping between an
icon and the spinner does not shift the layout.
