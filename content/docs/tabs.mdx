## API

**Main exports:** `Tabs`, `TabsList`, `TabsTab`, `TabsCount`, `TabsPanel`

Base UI tabs with a travelling Motion indicator; `segment`, `pill`, and `underline` variants; an
`appearance` for segment and pill; and two sizes.

| `appearance` | Track and selected chip |
| --- | --- |
| `default` | Muted track; raised `surface` chip with a hairline. |
| `solid` | Brighter (`border`) track; dark, borderless `background` chip. |
| `outline` | Bordered, unfilled track; `bg-muted` fill under the selected tab. Same heights as `default`. |

`underline` ignores `appearance`. The `solid` boolean is deprecated: `solid` maps to
`appearance="solid"`, and an explicit `appearance` wins over it.

| Variant | Outlined geometry |
| --- | --- |
| `segment` | Fill inset 3px from the border. 34px (`md`) / 30px (`sm`) tracks, the Input and Select heights; 8px corners around 4px fills (`md`), 7px around 3px (`sm`). |
| `pill` | Same padding as the filled pill; the tabs give up 1px of vertical padding to the border. Fully rounded. |

`TabsCount` renders a dim, tabular count after a tab's label, in any variant:

```tsx
<TabsTab value="included">
  Included <TabsCount>3</TabsCount>
</TabsTab>
```

The rectangular segment treatment uses the shared control tiers: an 8px track contains tabs
with 6px corners. The pill treatment remains fully rounded, and the underline treatment only
rounds its top corners.

`size` is `md` by default. `sm` drops a type step and tightens the padding, putting the pill
track at 32px — the height of an Input or a small Button — so a row of tabs lines up with the
controls beside it instead of standing a row taller. The segment radii step down with it, from
an 8px track around 6px tabs to a 7px track around 5px tabs, so the corners stay concentric at
both sizes.

## Scrolling and edge fades

Set `maxWidth` on `TabsList` to enable a horizontally scrolling bar in any variant.
Use a number for pixels (`maxWidth={280}`) or a CSS length (`maxWidth="20rem"`).
The bar also stays within its parent's width. Without `maxWidth`, the existing layout is unchanged.

An edge fades with a subtle, tapered blur only while there are more tabs hidden on that side. The fade includes the
track and the underline variant's dimmed rule. Touch and horizontal trackpad scrolling work
natively, with the scrollbar hidden. Clicking a tab in the half of the bar that has more
hidden content scrolls it toward the center, stopping at the beginning or end of the list.
Keyboard focus, initial selection, and externally controlled selection also reveal hidden tabs.
Reduced motion makes automatic scrolling immediate. Focus rings sit inside scrollable tabs
so they are not clipped. This option is intended for horizontal tab lists.
