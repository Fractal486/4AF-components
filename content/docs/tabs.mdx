## API

**Main exports:** `Tabs`, `TabsList`, `TabsTab`, `TabsPanel`

Base UI tabs with a travelling Motion indicator; segment, pill, and underline appearances; an
optional solid treatment; and two sizes.

The rectangular segment treatment uses the shared control tiers: an 8px track contains tabs
with 6px corners. The pill treatment remains fully rounded, and the underline treatment only
rounds its top corners.

`size` is `md` by default. `sm` drops a type step and tightens the padding, putting the pill
track at 32px — the height of an Input or a small Button — so a row of tabs lines up with the
controls beside it instead of standing a row taller. The segment radii step down with it, from
an 8px track around 6px tabs to a 7px track around 5px tabs, so the corners stay concentric at
both sizes.
