## API

**Main export:** `Switch`

A Base UI switch with a sliding thumb. With a mouse, hovering stretches the thumb 1.5px toward
the track's center and lightens the track; pressing stretches it 3.5px. On release the thumb
returns to a circle as it slides, and stays a circle until the pointer leaves.

`tone="adaptive"` (default) changes the thumb color with the checked state to contrast with the
track. `tone="fixed"` keeps the thumb dark in both states.

Use `checked` / `onCheckedChange` for controlled state or `defaultChecked` for uncontrolled
state. Call `details.cancel()` in `onCheckedChange(nextChecked, details)` to reject a toggle;
the checked state and thumb's motion direction both stay unchanged.
