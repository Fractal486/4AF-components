## API

**Main exports:** `AlertDialog` and its content, action, cancel, title, and description parts

A modal for confirming consequential actions. Backdrop clicks do not dismiss it; Escape and
close controls do. Place Cancel first, or set `initialFocus`, when cancellation should receive
initial focus.
