## API

**Main exports:** `HoverCard`, `HoverCardTrigger`, `HoverCardContent`, `HoverCardSkeleton`

A rich preview panel shown from hover or keyboard focus, with a built-in loading placeholder and
custom loading-content support.

`HoverCardTrigger` renders a link by default; give it an `href` so it is reachable by keyboard
and remains useful on touch devices. Keep essential information available at that destination;
the preview is supplemental content, not a modal or a focus-trapped interaction surface.
