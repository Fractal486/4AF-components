## API

**Main exports:** `Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`

A hand-animated unfolding Select with single or multiple selection and optional in-panel search.

## Sizing

Use `size="sm"` for a compact 32px control with 12px text and 14px glyphs, or `size="md"` for a
36px control aligned with medium Buttons and form Inputs. The size applies to both the trigger
and option rows. Use the default `sm` inside Command Palette.
