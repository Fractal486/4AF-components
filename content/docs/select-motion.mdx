## API

**Main exports:** `Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`

A hand-animated unfolding Select with single or multiple selection and optional in-panel search.

## Sizing

Use `size="sm"` for the 30px compact control or `size="md"` for the 34px form-row control. The size applies to both the trigger and option rows. Use the default `sm` inside Command Palette.
