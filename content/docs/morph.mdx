## API

**Main export:** `Morph`

Swaps icons or text with an animation. By default every item shares one grid cell sized to the
largest, so the surrounding control keeps its size during a swap. Under reduced motion the
swap is instant. Morph supplies no button styling, padding, or fixed height of its own.

Standard span props (`id`, `aria-*`, `data-*`, `style`, and event handlers) and a
`ref<HTMLSpanElement>` reach the outer span in every sizing mode. The element stays a span;
there is no `asChild` or `render` prop. With `sizing="current"`, measured width takes precedence
over `style.width`; other styles and the caller's `onTransitionEnd` are preserved.

`sizing` sets how the box is sized:

| `sizing` | Box size |
| --- | --- |
| `"widest"` (default) | The largest item, in every state. |
| `"current"` | The showing item. The width transitions over `--duration-base` and is instant under reduced motion. Without `ResizeObserver` the box resizes without animating. |
| `"fixed"` | The dimensions `className` gives it. Only the showing item mounts, so a known box carries no hidden sizing copies, and with them no duplicate controls or effects. |

The box carries `data-sizing`. With `current`, it also carries `data-resizing` while its width transitions between two measured sizes, so a caller can lift a truncation cap until the resize finishes (Badge does). A single item skips the hidden sizing copy unless
`sizing="current"` needs to measure its width. With `current`, you may supply just the current
label under its changing `activeKey`: Morph holds the previous measured width until the new
label is measured, then transitions smoothly. Hidden copies are excluded from assistive technology.

Hidden sizing copies keep each `LoadingIndicator`'s fixed-size wrapper but leave its loader
unmounted. This preserves the measured size without running hidden timers or spinner animations,
for both sizing modes. Other custom content still mounts in each sizing copy.

`morphVariants` exports the `initial` / `animate` / `exit` poses for content that has to stay
mounted while hidden, such as Action Button's icon-only pending label, which still names the
button. It then leaves and returns with the same motion as a keyed swap.
