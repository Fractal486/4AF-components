## API

**Main exports:** `ToastProvider`, `useToast`, `createToastManager`; type `ToastVariant`

A Base UI toast manager with list or collapsed-stack presentation, bottom-centre or bottom-right
placement, timers, focus handling, swipe dismissal, and up to three custom action buttons per
toast. Each toast can use the default title-and-description layout or the `title-only` variant.

## Variants

The `variant` field controls the toast's content layout independently from its status `type`:

| Variant | Content |
| --- | --- |
| `default` | Title plus an optional description (default) |
| `title-only` | Title only; the description slot is omitted |

```tsx
toast.add({
  title: "Changes saved",
  type: "success",
  variant: "title-only",
});
```

## Actions

Use `actions` for up to three custom buttons on one toast. The Base UI-compatible `actionProps`
option remains available when a single action is enough. Timers, focus movement, F6 navigation,
and swipe dismissal remain owned by Base UI regardless of presentation.
