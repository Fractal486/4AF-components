## API

**Main exports:** `Breadcrumb`, `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage`,
`BreadcrumbSeparator`, `BreadcrumbEllipsis`, `BreadcrumbCollapse`, `BreadcrumbSiblings`, `BreadcrumbSibling`

All parts except `BreadcrumbCollapse`, `BreadcrumbSiblings`, and `BreadcrumbSibling` accept native attributes and refs, plus `render` (an element or
render function) and `asChild`. Both replace the underlying element while keeping the part's styling,
attributes, event handlers, and refs. `asChild` takes precedence when both are supplied. Keep appropriate
navigation and list semantics when choosing replacement elements.

| Part | Element | Notes |
| --- | --- | --- |
| `Breadcrumb` | `nav` | `aria-label="Breadcrumb"` by default. |
| `BreadcrumbList` | `ol` | `size="sm" \| "md"` (default `md`): text, gap, and the separator, icon, and ellipsis sizes. `separator="slash" \| "chevron" \| "line" \| "dot"` (default `chevron`): the default glyph for every separator; reflected as `data-separator`. Wraps onto further lines. |
| `BreadcrumbItem` | `li` | One crumb. |
| `BreadcrumbLink` | `a` | `render` or `asChild` renders onto a framework link. Hover and focus bring it to `foreground`. A child `svg` is a leading icon, sized by the list's `size` (14px `sm`, 16px `md`). |
| `BreadcrumbPage` | `span` | The current page; `aria-current="page"`. Takes a leading `svg` icon, sized like a link's. |
| `BreadcrumbSeparator` | `li` | Presentational, hidden from assistive technology. Renders the list's `separator` glyph and carries it as `data-separator`; the chevron mirrors in RTL. Children replace the glyph and omit `data-separator`. |
| `BreadcrumbEllipsis` | `span` | Decorative alone. With `render` or `asChild` it can become a `button`, link, or menu trigger, gaining a hover fill, focus ring, open state (`aria-expanded` / `data-popup-open`), and a 40px hit area. An empty `asChild` child gets the dots. Give interactive ellipses an accessible name. |
| `BreadcrumbCollapse` | `li` + children | Hides its children behind an ellipsis, revealed in place or listed in a menu. |
| `BreadcrumbSiblings` | `button` + menu | A menu of sibling pages, opened from a button after the crumb's label. |
| `BreadcrumbSibling` | `a` | One row in that menu. Takes a leading `svg` icon, sized and muted as a Dropdown Menu row icon. |

### BreadcrumbCollapse

| Prop | Default | Description |
| --- | --- | --- |
| `variant` | `"expand"` | `"expand"` reveals the crumbs in place; `"menu"` lists them in a dropdown from the ellipsis. Reflected as `data-variant`. |
| `open` / `defaultOpen` / `onOpenChange` | — / `false` / — | Controlled or uncontrolled. With `expand`, the ellipsis only opens; close it by setting `open={false}`. With `menu`, this is the menu's open state. |
| `label` | `"Show full path"` | The ellipsis button's accessible name. |

Place it inside `BreadcrumbList` after the separator that precedes the hidden crumbs, and end the group
with a separator:

```tsx
<BreadcrumbItem><BreadcrumbLink href="/">Home</BreadcrumbLink></BreadcrumbItem>
<BreadcrumbSeparator />
<BreadcrumbCollapse>
  <BreadcrumbItem><BreadcrumbLink href="/docs">Docs</BreadcrumbLink></BreadcrumbItem>
  <BreadcrumbSeparator />
  <BreadcrumbItem><BreadcrumbLink href="/docs/components">Components</BreadcrumbLink></BreadcrumbItem>
  <BreadcrumbSeparator />
</BreadcrumbCollapse>
<BreadcrumbItem><BreadcrumbPage>Breadcrumb</BreadcrumbPage></BreadcrumbItem>
```

Closed, the trail reads `Home / … / Breadcrumb`. Group items and separators carry `data-breadcrumb-group`;
`data-collapsed` is added after their closing animation finishes. The collapse's own item carries
`data-state="open" | "closed"` and `data-transitioning` while animating. Its ellipsis is hidden after expansion
finishes. When the ellipsis had focus, opening moves focus to the first visible revealed link after the
animation settles; closing while focus is in the group returns it to the ellipsis after the exit finishes.
Moving focus elsewhere during an animation cancels that transfer.

With `variant="menu"`, the group's children render inside a [Dropdown Menu](/docs/dropdown-menu) panel,
written the same way: each `BreadcrumbLink` becomes a link row (`render` and `asChild` targets included),
a `BreadcrumbPage` a row marked `aria-current="page"`, and items and separators render no markup.
Icons in links and pages become the rows' leading icons.
`BreadcrumbSiblings` inside the group is omitted. One separator stays in the trail after the ellipsis.
The ellipsis is the menu trigger; the panel opens with the first enabled row highlighted.

### BreadcrumbSiblings

| Prop | Default | Description |
| --- | --- | --- |
| `open` / `defaultOpen` / `onOpenChange` | — / `false` / — | Controlled or uncontrolled menu state. |
| `label` | `"Sibling pages"` | The trigger button's accessible name. |
| `contentProps` | — | Passed to [Dropdown Menu](/docs/dropdown-menu)'s `DropdownMenuContent`: `side`, `align`, offsets, `className`, `portalProps`, `positionerProps`. |

### BreadcrumbSibling

Accepts `DropdownMenuItem` props.

| Prop | Default | Description |
| --- | --- | --- |
| `href` | — | The link target. |
| `render` | `<a href>` | Replaces the anchor, e.g. with a framework link. |
| `current` | `false` | Marks the row `aria-current="page"` and `data-current`, with a trailing check. |

Place `BreadcrumbSiblings` inside a `BreadcrumbItem`, after its `BreadcrumbLink` or `BreadcrumbPage`:

```tsx
<BreadcrumbItem>
  <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
  <BreadcrumbSiblings label="Navigation pages">
    <BreadcrumbSibling href="/docs/breadcrumb" current>Breadcrumb</BreadcrumbSibling>
    <BreadcrumbSibling href="/docs/menubar">Menubar</BreadcrumbSibling>
  </BreadcrumbSiblings>
</BreadcrumbItem>
```

The trigger carries `data-slot="breadcrumb-siblings-trigger"` and Base UI's `data-popup-open`, and is sized
by the list's `size`. The menu opens with the `current` row highlighted and focused, or the first enabled row
when none is current. Keyboard navigation, typeahead, dismissal, and focus return come from Dropdown Menu,
which installs with Breadcrumb.

## Motion

These apply to `variant="expand"`; the menu variant uses Dropdown Menu's panel motion.

- Crumbs expand and fade in, or shrink and fade out, before being hidden. The ellipsis makes the opposite
  transition. Changing direction mid-animation continues from the current widths and opacity.
- Width and inline margin intentionally animate so adjacent crumbs reflow as space opens or closes.
  Text is kept on one line and clipped only during the transition; normal wrapping returns at rest.
- Timing comes from `--duration-slow` and `--ease-out`. Reduced motion, or a browser without the Web
  Animations API, settles immediately and transfers focus without waiting.
