## Choose an implementation

| Component | Trigger model | Panel motion | Search model |
| --- | --- | --- | --- |
| Select | Button or field trigger | Scale, blur, and fade | Optional search inside the panel |
| Select Aligned | Button or field trigger | Opens *on* the trigger, scaling from the selected row | None |
| Select Search | Editable Combobox input | Standard positioned entrance | The trigger is the search field |
| Select Motion | Button or field trigger | Hand-animated unfolding panel | Optional search inside the panel |
| Select Motion Search | Editable Combobox input | Unfolds from the field | The trigger is the search field |

All support single and multiple selection except Select Aligned, which is single only — its
panel is positioned by the selected row, and there is no single row to align to once several
are chosen. Multi-selection uses the Checkbox component. The compact `SelectSortTrigger` belongs
to the base Select item.

Every implementation accepts `size="sm" | "md"`, defaulting to `sm`. The compact size is 32px
with 12px text and 14px glyphs; `md` is 36px and matches a medium Button and Input in form rows.
The size scales the trigger and option rows together. Inside Command Palette, always use `sm` so
the control fits the palette's density.
