## API

**Main export:** `ButtonGroup`

Joins two or more Buttons into one control: flattened inner corners, one hairline per seam, a
single outline around the run, horizontal or vertical orientation, with `variant` and `size`
passed down as defaults. Button sizes include the compact 24px `xs` step alongside `sm`, `md`,
and `lg`; icon-only children can use the matching `icon-xs`, `icon-sm`, `icon`, or `icon-lg`
sizes.
