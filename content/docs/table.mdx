## API

**Main exports:** `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`,
`TableCell`, `TableSort`

Native `<table>` semantics with the library's row rules, two densities, an optional checkbox
column, optional grid lines, and three-step column sorting. The Checkbox in the selection column
is Base UI's; the rest is plain HTML.

## Props

### Table

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md"` | `"md"` | Row density. |
| `bordered` | `boolean` | `false` | Frame around the table and a rule between every pair of columns. Row rules are always drawn. |
| `stickyHeader` | `boolean` | `true` | Pins the header row to the top of the scroll container. |
| `selectable` | `boolean` | `false` | Adds the checkbox column on the left. |
| `rows` | `readonly string[]` | `[]` | Row values the select-all covers. |
| `value` | `readonly string[]` | — | Selected row values, controlled. |
| `defaultValue` | `readonly string[]` | `[]` | Selected row values, uncontrolled. |
| `onValueChange` | `(value: string[]) => void` | — | Fired with the next selection. |
| `selectAllLabel` | `string` | `"Select all rows"` | Names the select-all checkbox. |
| `sort` | `TableSort \| null` | — | Active column and direction, controlled. |
| `defaultSort` | `TableSort \| null` | `null` | Active column and direction, uncontrolled. |
| `onSortChange` | `(sort: TableSort \| null) => void` | — | Fired with the next step of the cycle. |
| `wrapperClassName` | `string` | — | Class for the scroll container. |

### TableRow

| Prop | Type | Description |
| --- | --- | --- |
| `value` | `string` | Makes the row selectable and names it in the selection. |
| `selectLabel` | `string` | Names this row's checkbox. Defaults to `"Select row"`. |

### TableHead

| Prop | Type | Description |
| --- | --- | --- |
| `sortKey` | `string` | Makes the column sortable and names it in `TableSort.column`. |

`TableSort` is `{ column: string; direction: "asc" \| "desc" }`.

## Selection

`selectable` adds the column; the rows are unchanged. Each `TableRow` renders its own cell: a
select-all `<th>` in the header, a checkbox `<td>` in the body, and an empty cell in a footer or
for a row without a `value`, so columns stay aligned.

`rows` sets what select-all covers — pass the page being rendered, not every row held. Selecting
all is a union, so selected values outside `rows` are kept. The header checkbox is indeterminate
while the selection is partial and checks from there.

Rows expose `data-selected`. `aria-selected` is not set, being invalid on a plain `table` row.

## Sorting

`sortKey` turns a header into a button that cycles ascending, descending, unsorted. Switching
columns restarts at ascending. `aria-sort` is set on the `<th>`, and a header without a
`sortKey` stays a plain header.

Ordering the rows is the caller's, since only the call site knows what the values are:

```tsx
const [sort, setSort] = useState<TableSort | null>(null);
const rows = useMemo(() => sortPeople(people, sort), [people, sort]);

<Table sort={sort} onSortChange={setSort}>
  <TableHead sortKey="name">Name</TableHead>
```

## Layout

The table ships inside a scroll container carrying the library's thin scrollbar, styled with
`wrapperClassName`. With `bordered` the frame is drawn on that container rather than on the
table, so its corners round; `border-collapse` ignores `border-radius`.

The header pins to that container, which needs a bounded height before it has anywhere to pin
to:

```tsx
<Table wrapperClassName="max-h-80">
```

Pinned header cells take `bg-background`, since rows scroll underneath them. Pass another fill
through `className` on `TableHead` when the table sits on a raised surface. They also sit at
`z-20`, above cell content that positions itself — a Badge's label is at `relative z-10`.

Borders are separated (`border-separate` with zero spacing) rather than collapsed, because a
collapsed border belongs to the table and a pinned cell would travel without its edge. Every
rule therefore lives on the cells; a `<tr>` draws only its background.
