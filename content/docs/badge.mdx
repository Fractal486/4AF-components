## API

**Main exports:** `Badge`, `BadgeIconsProvider`, types `BadgeStatus` and `BadgeIcons`

`status="loading"` accepts `loader={<MySpinner />}` or inherits
[LoaderProvider](/docs/reference/engineering#shared-loading-indicators), with ASCII as the fallback.
An explicit `icon` takes precedence, and `icon={null}` hides it.

## Status icons

| Status | Default icon |
| --- | --- |
| `neutral` | `Circle` |
| `info` | `Info` |
| `success` | `Check` |
| `warning` | `AlertTriangle` |
| `danger` | `OctagonAlert` |
| `loading` | Shared loader (`loader`, then `LoaderProvider`, then ASCII) |

| Prop / part | Description |
| --- | --- |
| `icon` | One glyph for this badge, whatever its status. |
| `icons` | Per-status glyphs for this badge, e.g. `{ danger: <CircleX /> }`. Unnamed statuses fall through. |
| `BadgeIconsProvider icons={…}` | Per-status glyphs for every badge in a subtree, portals included. Nested providers merge over outer ones. |

Precedence, most specific first: `icon`, `icons`, `loader` (loading only), `BadgeIconsProvider`,
the default. A `null` entry in `icons` or the provider hides the icon for that status. Glyphs are
sized to the badge (`size-2.5` / `size-3` / `size-3.5`) unless they set their own size.

```tsx
<BadgeIconsProvider icons={{ danger: <CircleX />, success: <CircleCheck /> }}>
  <App />
</BadgeIconsProvider>
```

A status badge with outline and status treatments, an optional icon or dot, and animated label
and glyph changes powered by the shared `Morph` component.

The default size is `sm`. Boxed badges are 16px high with a 4px radius at `sm`, 20px high with
a 4px radius at `md`, and 24px high with a 6px radius at `lg`. The `plain` variant remains
boxless at every size. The default `shape` is `rounded`; use `shape="pill"` for fully rounded
boxed badges.

## Variants

`plain` has no background or outline. `solid` uses a semi-transparent status-coloured fill,
with the text and icon in the same, more visible status colour. `outline` has no fill and
always uses a gray outline; only its text and icon colour changes with `status`.

## Shape

`rounded` preserves the compact corner radius used by default. `pill` gives `solid` and
`outline` badges a fully rounded shape; it has no visible effect on the boxless `plain` variant.

## Layout animation

Badge animates its width when its content changes. Set `animateLayout={false}` for a
static badge inside a list that filters or reorders, such as a Command Palette or table row.
Otherwise it FLIP-animates its own position as the row moves—sliding within a row that does not
animate and adding layout cost. A badge whose content actually changes keeps the default.

```tsx
<Badge animateLayout={false}>Beta</Badge>
```
