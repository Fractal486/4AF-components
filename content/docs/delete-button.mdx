## API

**Main export:** `DeleteButton`

A quiet destructive button that arms on the first deliberate press and confirms on the second.
Escape, blur, and timeout disarm it.

`size` uses the Button scale: `xs` is 24px, `sm` is 30px, `md` is 34px, and `lg` is 38px.
