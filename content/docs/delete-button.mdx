## API

**Main export:** `DeleteButton`

A destructive confirmation button: the first press arms it and a later press calls `onDelete`.
Presses within 350ms of arming are ignored so a double-click cannot confirm. Escape, blur, and
`resetAfter` disarm it; the timeout defaults to 3000ms, and `resetAfter={0}` disables the timeout.

`variant` accepts `outline` (default), `ghost`, or `plain`, all with destructive text.
`armed` / `onArmedChange` control the armed state, or use `defaultArmed` for an uncontrolled
initial state. The button requests disarming before calling `onDelete`; it does not await that callback
or show pending, success, or error states.

By default the button keeps the width of its wider state. `sizing="current"` fits it to the
showing state and animates the width when it arms and disarms. The button carries
`data-sizing`.

`size` uses the Button scale: `xs` is 24px, `sm` is 30px, `md` is 34px, and `lg` is 38px.
