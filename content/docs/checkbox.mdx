## API

**Main export:** `Checkbox`

A Base UI checkbox with an animated drawn tick, controlled and uncontrolled state, and an
optional click-target label.

Checkbox has one fixed compact geometry: a 16px box with a 4px corner radius. It does not
expose a `size` prop; use the optional `label` and surrounding layout to provide context.
