## API

**Main export:** `Toggle`

A Base UI pressed/unpressed control using the Button appearance and sizes, with optional
icon-fill behaviour and `pressScale={false}` support. `shape="pill"` rounds it fully, making the
square icon sizes circles; the default is `rectangular`. The toggle carries `data-shape`.
